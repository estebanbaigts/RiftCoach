# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on https://github.com/estebanbaigts/RiftCoach.

Include: affected version/commit, platform, reproduction steps, impact. Please never include real API keys or personal data in a report.

We aim to acknowledge within 7 days and to agree on a disclosure timeline with you.

## Scope

In scope: the desktop app, its build/release pipeline, data validation, storage, CSP and Tauri configuration.
Out of scope: Riot Games services (report those to Riot), issues requiring a compromised OS.

## Supported versions

Pre-1.0: only the latest commit on `main` and the latest pre-release receive fixes.

See also [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).
