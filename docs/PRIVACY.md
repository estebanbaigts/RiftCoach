# Privacy / Confidentialité

**Current version (demo mode):** RiftCoach makes no network request, has no account, no telemetry, no analytics, no crash reporting and no AI service. Data shown is synthetic.

Stored locally (webview storage, key prefix `riftcoach:v1:`): display preferences (theme, language), demo epoch, simulated demo games, demo goals. Delete them via **Settings → Local data → Reset demo**, or by uninstalling the app.

**Future real-data mode** (not implemented): game data fetched from official Riot APIs for the Riot ID you enter, stored only on your device, deletable at any time. Any optional external service (e.g. an AI assistant) will require explicit opt-in and show exactly what is sent. A full privacy policy will be published before any production release.

---

**Version actuelle (démo) :** aucune requête réseau, aucun compte, aucune télémétrie, aucun service d'IA. Les données affichées sont fictives. Les préférences et l'état de la démo sont stockés localement et supprimables depuis **Paramètres → Données locales**.
